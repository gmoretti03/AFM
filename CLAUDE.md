# AFM

AFM (Atomic Force Microscopy) data-analysis project — University of Milano-Bicocca, Monza.
Scientific goal: measure the mechanical properties (stiffness / elastic modulus) of tumour cells from
force–distance curves collected with an AFM cantilever, comparing cell lines and measurement regions.

## Raw data

`Code_General/Curve di forza belle/<group>/*.jpk-force` — native JPK files (actually zips containing
`header.properties` + segments). Four experimental groups:

- `Petri20k_MCF7R_t48h_cito_20260225` (55 files)
- `Petri20k_MCF7R_t48h_nucleo_20260225` (60 files)
- `T47DR_t48h_cito_20260318` (59 files)
- `T47DR_t48h_nucleo_20260318` (83 files)

The group name encodes cell line (`MCF7R` / `T47DR`, both breast-carcinoma lines), measurement region
(`cito` = cytoplasm, `nucleo` = nucleus), time (`t48h`) and experiment date (`YYYYMMDD`). The metadata are
parsed from the folder name by `parse_group_name()` in notebook 01. The labels `cito`/`nucleo` are kept as
data identifiers throughout the code.

Each `.jpk-force` file contains at least 2 segments: `segment 0` = extend/approach (candidate for the
mechanical fit), `segment 1` = retract (useful for adhesion/hysteresis).

## Analysis pipeline (stages)

1. **01** (done): reads all `.jpk-force` files, exports every segment to CSV, saves metadata, builds the
   `segment0/extend` summary and a **preliminary instrumental QC** (global and per-group robust z-scores).
   **No curve is discarded**: the QC is diagnostic only. Produces `afm_output/manifests/segment0_manifest.csv`.

2. **02** (done): robust linear baseline on the first 30% of the curve (in `segment0` z decreases: baseline
   at the START of the array, contact towards the end; the prototype `Preliminary/02_v4` used the wrong side),
   threshold contact point, fit `F = A·δ^(3/2)` with `A` and `z_c` free, good/suspicious/bad flag
   (informative), 9 preprocessing variants (`afm_tools.VARIANTS`), adhesion features from the retract.
   `A` is an effective parameter (nN/µm^3/2), not the Young modulus (`tip_radius` is absent from the metadata).
   Writes `results/fit_results_segment0.csv` and `results/fit_variants.csv`.

3. **03** (done): frequentist analysis of `log A` for 4 groups (2 lines × 2 regions): MLE with `iminuit`,
   profile of Δ = μ_nucleus − μ_cytoplasm, toy MC (bias/pull/coverage/size/power), line×region interaction,
   Holm, systematics with the Barlow criterion. Output `results/03_summary.json`.

4. **04** (done): Bayesian analysis: `emcee`, Bayes factor by numerical marginalization versus prior width,
   prior sensitivity, posterior predictive check, Student-t (WAIC), hierarchical model, credible vs profile
   coverage at low statistics. Output `results/04_summary.json`.

5. **05** (done): synthetic curves with 5 injected defects (`no_contact`, `saturation`, `huge_noise`, `jump`,
   `wrong_slope`) to measure the efficiency of Isolation Forest / robust Mahalanobis (trained on the real
   curves, no curve discarded), cytoplasm/nucleus classification with CV, permutation and transfer between
   lines, Gaussian mixtures. Output `results/05_*`.

6. **06** (done): ML on the curve *shape* (60-point resampled force–indentation curves in `results/curves_resampled.csv`):
   PCA, clustering, classification from shape vs scalar features, conformal prediction, learning curves,
   PCA-reconstruction anomaly detector, and a model-independent check (force at fixed indentation 150/300 nm)
   that confirms the nucleus-softer result. Note: `max_indentation` is a function of `A` at constant setpoint force,
   so it must not be used as an independent covariate. Output `results/06_*`.

7. **07** (done): depth-resolved profiles (`results/force_indentation_profiles.csv`): nucleus−cytoplasm Δ vs indentation,
   fixed-force check, effective stiffness vs depth; the T47DR shape signal is stable under contact-point shifts but is
   entirely the local exponent (nucleus 1.50 vs cytoplasm 1.43). Output `results/07_summary.json`.

8. **08** (done): uses the JPK timestamps (`results/acquisition_times.csv`). Cytoplasm and nucleus were measured in separate,
   non-overlapping time blocks in both sessions (region ≡ time); curves come in bursts of 3-5 at the same spot (ICC 0-0.18,
   design effect ~1.4). MCF7R result robust; T47DR stiffness difference is compatible with a time drift (Δ at common time 0.05±0.17),
   while the T47DR exponent difference survives. Output `results/08_summary.json`.

9. **09** (done): calibration metadata per session (`results/session_calibration.csv`): same cantilever, spring constant differs by 40%
   between sessions → line comparisons not interpretable; within-spot repeatability sd 0.33-0.61; preconditioning (first curve stiffer).
   First-curve-only Δ: MCF7R −0.77±0.13, T47DR −0.01±0.26. Output `results/09_summary.json`.

10. **10** (done): single Bayesian model (region + drift + position + burst effect). MCF7R β≈−0.8/−0.9 robust; T47DR stiffness β depends on
   the drift prior (−0.2 without drift, +0.03 with it); T47DR exponent excess robust. Output `results/10_summary.json`.

Known limits to keep in the conclusions: region ≡ time block within each session, pseudo-replication (no cell id; bursts used as proxy), cell line ≡ experimental session
(different dates), pre-selected sample ("good curves").

`Preliminary/` holds the superseded exploratory notebooks: useful as a reference for the logic already
developed, but not the "live" code.

## Code conventions

- Notebooks, comments and documentation are in **English**; keep this language for consistency.
- Every final notebook starts with a markdown cell that states explicitly what it does and what it does
  **not** do (see cell 0 of 01), and ends with a cell describing the output produced and the next expected
  notebook — keep this pattern in new notebooks.
- Tables used by notebooks 03-05 go in `Code_General/results/` (tracked); `afm_output/` stays a cache.
- Notebook 01 writes an `afm_output/README_outputs.txt` documenting every generated output subfolder
  (`csv_curves/`, `metadata/`, `summaries/`, `manifests/`, `plots_overview/`, `plots_qc/`) — update it if the
  output schema changes.
- The preliminary QC (notebook 01) is philosophically different from the QC of notebooks 02/03: the first is
  diagnostic only and excludes nothing; curve exclusion must happen further downstream, after the fit,
  explicitly and traceably.
- `afm_output/` is entirely regenerable from notebook 01 starting from `Curve di forza belle/`: treat it as a
  cache, not as a source of truth.

## ML / statistics component on synthetic data

`Docs/afm_ml_stat_project_presentation.html` (local only, git-ignored) documents a preparatory mini-project on
**1000 synthetic AFM curves** (950 good + 50 with injected instrumental defects: `no_contact`, `saturation`,
`huge_noise`, `jump`, `wrong_slope`), a validation of the general pipeline before applying it to the real JPK data.
Notebook 05 reuses the idea with a generator calibrated on the real curves.
